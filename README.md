# ThrustlineNG

Reconstruction de Thrustline sur un socle reproductible et sécurisé.

Le dépôt ne contient pour l'instant que les versions des outils et les scripts
de préparation. Consultez [docs/SETUP.md](docs/SETUP.md) pour démarrer.

Le shell desktop minimal se lance depuis la racine avec `pnpm desktop:dev`.
